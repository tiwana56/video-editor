Aam Sawalat

Video kahan save hoti hai?
Sab editing phone ke browser ke andar hoti hai. Koi server nahi, video kahin upload nahi hoti.
Galti ho jaye to? Undo / Redo kaise kaam karta hai?
Screen ke sab se upar naam wale bare button hain: Undo = pichla step wapas (kaata hua hissa, delete shuda clip, split, trim, tartib, gap, frame size, rang — sab wapas aa jata hai), Redo = undo kiya hua step dobara. Jo button chal sakta hai wo cyan kinare ke sath saaf dikhta hai; halka (band) button matlab abhi us ke liye kuch hai hi nahi — pehle koi edit karein, phir Undo khul jayega. Keyboard par Ctrl+Z = Undo, Ctrl+Y = Redo. Aakhri 50 steps tak wapas ja sakte hain.
Page Refresh button kya karta hai?
Upar Refresh button page ko dobara load karta hai — page atak jaye ya kuch garbar lage to yehi dabayein. Khayal rahe: jo editing abhi Export nahi hui, refresh se wo khatam ho jayegi, is liye dabane par pehle chetawni aati hai — yaqeen ho to dobara dabayein. Phone mein rakhi asal video files ko kuch nahi hota, wo dobara import ho jayengi.
Export format?
Android Chrome par aam taur par MP4 ya WebM — dono YouTube par upload ho jate hain.
Gemini key mehfooz hai?
Key aik dafa dalne par isi browser (local storage) mein save ho jati hai taake bar bar na dalni pare — kisi server par nahi jati, sirf jawab ke waqt Google ko bheji jati hai. Browser ka data clear karein to key bhi delete ho jayegi.
Lambi video?
1–3 minute ki clips sab se smooth chalti hain. Lambi tilawat se Shorts ke chhote hisse trim karein.
Screen size / frame kahan hai — Short, TikTok ya long video?
Preview ke bilkul neeche bara “📐 Screen Size / Frame” bar hai (Editor → Media panel mein bhi wahi option hai): 9:16 = Shorts / TikTok / Reels (vertical), 16:9 = long video / YouTube (horizontal), 1:1 = square post, 4:5 = portrait post, Original = video jaisi hai waisi. Agar video frame se size mein mukhtalif ho aur side se kat rahi ho to usi bar mein “Pura Video Dikhe” chunein — kuch nahi katega, peeche dhundla background aa jayega. Chuna hua size Export par bhi wahi lagega.
Timeline (edit bar) aagay nazar nahi aati / scroll nahi hoti?
Bar par ungli rakh kar left/right slide karein — timeline scroll ho jayegi; ya timeline ke upar wale ◀ Peeche / Aagay ▶ buttons dabayein. Video chalte waqt bar khud playhead ke sath aagay barhti rehti hai, is liye agla hissa chop nahi hota. Poori video aik screen par dekhni ho to “Fit” dabayein.
Video kaat kar chhota clip banana — sab se asan tareeqa?
Editor → Trim mein neeche sunehri frame wala “✂️ Video Kaato — Sirf 3 Asan Steps” khana hai. Step 1: video chala kar jahan se clip shuru karna hai wahan rokein aur “🟢 Yahan Se Shuru Karo” dabayein. Step 2: jahan khatam karna hai wahan rokein aur “🔴 Yahan Khatam Karo” dabayein — neeche wali line mein chune hue hisse ka time nazar aayega. Step 3: “✂️ Kaat Do” dabayein — baqi sab kat jayega, sirf wahi hissa reh jayega. Kaatne se pehle “▶ Pehle Ye Hissa Chala Kar Dekh Lo” se check bhi kar sakte hain (wo kaatega nahi, sirf dikhayega). Phone mein rakhi asal video file waisi hi rehti hai — galti ho jaye to dobara import kar lein. Neeche wale sliders sirf thora sa aage/peeche theek karne ke liye hain, aam taur par un ki zaroorat nahi.
Kai clips aik video mein?
Import mein kai clips aik sath chunein — har clip ki asal lambai khud pehchan li jati hai, is liye timeline mein sab clips apni sahi jagah par barabar nazar aate hain. Har clip ka apna trim set karein, timeline mein clip ko drag karke ya Media list ke ↑ ↓ se tartib rakhein — Export sab ko jod kar aik video bana dega. Do clips ke darmiyan khali hissa (gap) chahiye to clip select karke “Gap +1s” dabayein.
Audio alag kaise?
“Audio Alag Karein” hisse se trim wala hissa ya poori video ki awaz WAV file mein download ho jati hai. Timeline mein “Audio Alag (Track)” karein to audio alag track ban jata hai — usay select karke “⬇ Ye Audio Download Karein (WAV)” se wahi hissa file mein bhi mil jata hai.
Audio track par Split / Trim / Delete kaise?
Timeline ki Audio wali line mein track par tap karke select karein — neeche video clips jaisay hi button aa jayenge: “✂️ Split (Playhead Par)” = playhead wali jagah se track do hisso mein; “⏮ Trim Left” = playhead se pehle wala hissa kat jayega; “Trim Right ⏭” = playhead ke baad wala hissa kat jayega; “🗑 Audio Track Delete” = poora track delete. Misal: beech ka ghalat hissa nikalna ho to pehle wahan Split, phir aakhir par Split, phir beech wala hissa select karke Delete kar dein. Track ke kinare kheench kar bhi trim hota hai. Galti ho jaye to upar Undo dabayein — kata/delete hua hissa wapas aa jayega. (Sirf “Sab clips ki aik audio” wala combined track khud clips se banta hai, us par Split/Trim nahi lagta — kisi aik clip ki awaz kaatni ho to pehle us ka alag track banayein.)
Teeno / sab videos ki AIK hi audio?
Audio hisse mein “Sab Clips Ki AIK Audio Banayein (WAV)” dabayein — timeline ki sab clips aik hi audio file mein tartib se jud jati hain (har clip ka trim wala hissa). Timeline ke project tools mein “Sab Clips Ki Aik Audio (Track)” se wahi cheez aik combined track ki surat mein bhi banti hai, wahan se bhi WAV download ho jata hai.
Saari audio AIK file mein download karni hai — button kahan hai?
Neeche wale Audio tab mein jayein — sab se upar sunehri (gold) frame mein sab se bara button hai: “🎵 Sab Audio Merge Karein — AIK File Download (WAV)”. Wahi dabayein, saari clips ki awaz aik hi WAV file mein download ho jayegi. Alag-alag clip select karne ki zaroorat nahi — sab khud aik sath select hai.
Poori video aik hi select / merge karni hai?
Editor → Trim (timeline) ke upar “✓ Sab Select Karein” dabayein — poori video (sab clips mila kar) aik hi select ho jayegi. Phir wahan “🎬 Sab Merge — AIK Video” dabayein ya upar wala Export Video button — sab clips jud kar aik hi video file ban jayegi.
Apni audio file video mein merge karna — video ka sound band?
Audio hisse ke “Merge” wale khane se apni audio file (MP3/WAV) chunein — file lagte hi video ka apna sound khud band ho jata hai aur preview + export dono mein sirf usi audio ki awaz chalti hai. Wapas video ka sound chahiye to wahi toggle OFF kar dein, ya “Merge Audio Hatayein” dabayein.
Audio file upload karne ka button kahan hai?
Do jagah bara button hai: (1) Editor → Media panel mein video import ke neeche “📤 Audio File Upload Karein (MP3 / WAV)”, (2) Audio tab mein sab se upar neela button “📤 Apni Audio File Upload Karein — Video Mein Lagayein”. Koi sa bhi dabayein, phone se audio file chunein — file lagte hi video ka apna sound band ho jayega aur sirf upload ki hui audio chalegi.
Logo kaise lagayein — aur wo agay-peeche kyun hota tha?
Editor → Media panel mein sunehra button hai: “🏷️ Logo Lagayein — Poori Video Par Fixed” — wahan se apna logo (PNG) chunein. Pehle logo playhead wali jagah se shuru hokar usi waqt ke kul waqt par khatam ho jata tha, is liye baad mein clips jodne se wo beech mein gayab/agay-peeche ho jata tha. Ab logo FIXED lagta hai: poori video par shuru se aakhir tak, aik hi kone mein — chahe kitne bhi clips jod dein, na gayab hoga na hilega. Kona badalna ho to neeche timeline ki Logo wali line mein logo par tap karke select karein — wahan chaaron konon (Upar Right / Upar Left / Neeche Right / Neeche Left) ke button aur halka (opacity) karne ka slider milega. Delete bhi wahi se hota hai.
Video mein tasveerein (images) kaise add karein?

Phir Export dabayein — tasveerein usi tartib mein video ke andar chalengi.
Tasveer video ke SHURU ya BEECH mein kaise lagayein — sirf end par kyun lagti thi?

Shuru Mein: tasveer sab se pehle aayegi. End Mein: sab se aakhir mein. Agar tasveer pehle se lagi hui hai to timeline mein usay select karke “⏮ Sab Se Shuru Mein” / “📍 Playhead Par” / “⏭ Sab Se End Mein” buttons se us ki jagah kabhi bhi badal sakte hain.
