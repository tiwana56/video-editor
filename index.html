📲 App Install Karein — Home Screen Par Logo Ke Sath
  1. Ye page Chrome mein kholein.
  2. Upar wala 📲 Install App button dabayein — ya Chrome ke ⋮ menu → “Add to Home screen” / “Install app” chunein.
  3. Install dabate hi ProCut Studio ka logo wala icon home screen par aa jayega — phir editor aik asli app ki tarah khulega, baghair browser bar ke.
  4. Agar install ke baad 404 aaye: is ki wajah purana home-screen icon hota hai jo pehle wali ghalat link par bana tha — naya install usay khud replace nahi karta. Pehle purane ProCut icon ko home screen par long-press karke Delete / Uninstall karein, phir isi page ko Chrome mein dobara khol kar phir se Install karein. Manifest ki link ab durust kar di gayi hai, is liye taza install editor par hi khulna chahiye. Agar phir bhi 404 aaye to Chrome ki Settings → Site settings mein is site ka purana data clear karke dobara install karein.

Aam Sawalat

Video kahan save hoti hai?
Sab editing phone ke browser ke andar hoti hai. Koi server nahi, video kahin upload nahi hoti.
Export format?
Android Chrome par aam taur par MP4 ya WebM — dono YouTube par upload ho jate hain.
Gemini key mehfooz hai?
Key sirf page ki memory mein rehti hai, kahin save nahi hoti. Sirf jawab ke waqt Google ko bheji jati hai.
Lambi video?
1–3 minute ki clips sab se smooth chalti hain. Lambi tilawat se Shorts ke chhote hisse trim karein.
Kai clips aik video mein?
Import mein kai clips aik sath chunein, har clip ka apna trim set karein, ↑ ↓ se tartib rakhein — Export sab ko jod kar aik video bana dega.
Audio alag kaise?
“Audio Alag Karein” hisse se trim wala hissa ya poori video ki awaz WAV file mein download ho jati hai.
Thumbnail?
Thumbnail Studio mein video ke frame se — ya Gemini AI background se — 1280×720 JPG thumbnail banta hai, Urdu text ke sath.
Install ke baad 404 kyun aata hai?
Purana home-screen icon pehle wali ghalat link par bana hota hai aur naya install usay khud nahi badalta. Usay long-press karke delete karein, phir is page ko Chrome mein khol kar dobara Install karein — manifest ki link ab durust hai, is liye taza icon editor par khulna chahiye.
